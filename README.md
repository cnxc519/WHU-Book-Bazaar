# WHU二手书市 · 校园二手书市平台

面向在校学生的校园二手书市：发布闲置教材（书名/课程/成色/价格，支持**拍一张合照 AI 批量识别上架**）→ 同学浏览联系 → 线下当面验书付款。

**平台不碰钱**：无充值、无余额、无提现、无抽成，费用完全由双方线下当面结算；金额仅作双方参考。

**数据按学校隔离**：每个学校只能看到自己学校的在售书籍（浏览/搜索/详情/联系均限本校）。


## 项目结构

```
LeLeBook/
├── server/          # 服务端（Node.js + Express + SQLite，零原生依赖）
│   ├── src/         # auth(登录) / books(书市) / book-chats(私聊) / invite(邀请) / misc / admin
│   ├── admin/       # 管理后台网页（学校/公告/用户/书市举报/版本）
│   ├── deploy.sh    # 一键部署脚本（本地执行，目标 8901 端口）
│   └── config.json  # 服务端配置（端口/SMTP/AI/管理员密码，不入库）
├── app/             # Android 客户端（Qt 6 QML + C++，CMake 工程）
│   ├── qml/         # 界面（书市/卖书/消息/邀请/我的 五 Tab + 各页面）
│   ├── src/         # C++：Session(会话+multipart上传) / ImageUtil / Updater
│   └── android/     # AndroidManifest（包名 com.lele.book / 权限 / FileProvider）
└── docs/            # 构建文档
```

## 功能

- **卖书**：单本发布（书名/课程/成色/价格 0.01~999.99 元 + 封面照）或**批量发布**——把一摞书拍一张合照，服务端调 GLM 视觉识别书名，核对增删改后一次上架；地点写一遍，价格可用一句文字描述（如"左边10r/本，右边20r/本"），合照作为每本书的封面
- **书市浏览**：搜索（书名/课程/说明/价格描述，支持缩写模糊匹配）、排序（最新/价格）、封面、成色与课程标签
- **书详情**：封面完整展示、价格/价格描述、卖家主页（在售/已售统计）、联系卖家、举报
- **书市私聊**：卖家-买家长期会话，支持文字与位置消息
- **消息通知**：铃铛通知（有人想买你的书等）+ 未读角标
- **邀请**：邀请码 + 好友关系（无经济奖励）
- **自动清理**：在售书籍上架满 1 年自动下架、心愿发布满 2 个月自动下架（重新上架时效重新计），不让僵尸信息长期占据平台，又不至于让书市显得空荡
- **我的**：头像、昵称、公告中心、版本更新

## 网页版（主推）

部署后浏览器直接访问 `http://服务器IP:8901/` 即为网页版（移动端优先，免安装），
注册/登录、书市浏览搜索、书籍详情、单本+批量(AI 识别)发布、我的书管理、
书市私聊、消息通知、邀请，全部能力与 App 一致。APK 版保留作为增强版。

## 本地开发

```bash
# 服务端（默认 8901 端口，dev_mode 验证码直接返回）
cd server
cp config.example.json config.json   # 修改 jwt_secret / SMTP / AI key
npm install
node src/index.js

# 客户端（Qt Creator 打开 app/CMakeLists.txt，选 Desktop 或 Android Kit 构建）
# App 内「我的 → 设置」可改服务器地址
```

## 发布更新

1. 修改代码 → `app/CMakeLists.txt` 的 `APP_VERSION_CODE` 改为新版本号
2. 构建 Release APK（管理后台「版本更新」上传，填相同版本号）
3. 管理后台设置最低可用版本号（低于它的设备强制更新）

## 安全注意事项

- `server/config.json` 含 JWT 密钥、SMTP 授权码、AI API Key，已在 .gitignore 中排除，**严禁提交**
- APK 禁止公开直链下载（/files/apk 返回 404），App 内走 10 分钟签名链接，推广走 /dl/latest
